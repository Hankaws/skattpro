# Fiken Research – konkrete ideer for SkattPro

## 1. Fiken hovedfunksjoner
- Regnskapsføring med bankkobling
- Faktura og betaling
- Skattemelding og årsregnskap
- Lønn, lønnsslipp, pensjon
- Kvitteringer og fradrag
- Integrasjoner med banker, kassasystemer, nettbutikk

## 2. Integrasjoner Fiken tilbyr
- Bank
- POS / kassasystem
- Abonnementssystem
- Nettbutikk
- Fagsystem
- Fakturaverktøy
- Offentlige tjenester via API

## 3. Brukerreise Fiken bruker
- Enkel start: bruker lager bedrift
- Onboarding-guide
- Snapshots / bekreftelser underveis
- Gratis prøveperiode

## 4. Prising
- Prøveperiode
- Abonnement basert på antall transaksjoner eller brukere
- Gratis nivå for små brukere

## 5. Konkrete forbedringsforslag til SkattPro
### Umiddelbart (ingen backend)
- Kopier Fikens korte brukerreise: "1) Lag bedriftsprofil → 2) Legg til ansatt → 3) Eksporter"
- Legg til snarvise CTAer på hver side
- Lag eksportforberedelser for regnskap: CSV, Excel, JSON er klare; legg til template-beskrivelser
- Gjør "Pris"/"Pro" tydeligere med eksempler på hva du får

### Etter hvert
- Bankkobling via open banking API
- Automatisk kategorisering av utgifter
- Lagring av kvitteringer
- Fakturamal + innbetaling
- Integrasjon med bokholdingsystemer
